# Project Instructions

* Preserve all existing documented business rules unless explicitly instructed to change them.
* Do not introduce technologies, frameworks, services, or infrastructure that belong to a later milestone.
* Stay within the scope of the current milestone and task.
* Run the relevant test suite after making code changes.
* If tests fail, report the failures and do not hide or bypass them.
* Before making a decision that would change documented business behavior, flag it for review instead of assuming.
